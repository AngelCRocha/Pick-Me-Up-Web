# Pick Me Up

A simple, swipeable motivational message card app. Swipe through uplifting messages or submit your own to brighten someone's day.

## Features

- Swipe left to see a random motivational message
- Submit your own pick-me-ups (up to 200 characters)
- User-submitted messages are saved locally and persist between sessions
- Smooth card animations for a satisfying experience
- Works on both mobile (touch) and desktop (mouse)

## How to Use

1. Open `pickmeup.html` in any web browser — no install or build step required
2. Swipe left on the card (or click and drag) to see a new message
3. Tap **Submit Pick Me Up** to write and post your own message

## Built With

HTML, CSS, and JavaScript — no frameworks or dependencies.
